Android uses `Noto-COLRv1.ttf` throughout the app, registered as the Flutter
font family `NotoColorEmoji`. The editor, pickers, and chat text share this
single font. Its scalable color outlines keep enlarged emoji sharp.
iOS continues to use its system emoji font.
